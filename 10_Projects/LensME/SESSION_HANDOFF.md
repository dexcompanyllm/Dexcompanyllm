1. 등록 PR/main 상태와 최신 계약을 확인해요.
2. 실제 기존 코드 저장소·프로젝트 첨부·인계 패키지를 최소 범위로 탐색해요. 기존 파일명 PROJECT_INSTRUCTIONS/START_SOL을 찾되 존재한다고 단정하지 않아요.
3. 코드 위치·미커밋 변경·기술 스택·테스트 명령을 확인해 PROJECT_CONFIG에 기록해요.
4. `Design/DESIGN_GUIDE.md`의 대표 LIVE 화면부터 구현해요. 승인 이미지의 텍스트/데이터를 그대로 추출해 상품 DB로 만들지 않아요.
5. 실기기/운영 연동 없는 항목은 Not Checked로 유지해요. 검증 가능한 문서/DEMO/단위 테스트는 계속해요.

## 알려진 자료 접근 제한

Library 검색에서 v1.0 가이드의 일부 내용은 확인했지만 본문 읽기 2회는 429와 file visibility 오류로 실패했어요. 이번 작업에서는 같은 읽기를 더 반복하지 않고 검색에서 확인된 내용만 참고했어요. GitHub 문서와 현재 사용자 원문/승인 이미지는 별도로 확인했어요. 기존 코드·인계 ZIP의 실재와 위치는 후속 discovery에서 검증해요.

## 최소 승인/행동
