## Gate 판정

- 문서 Gate: 출처/범위/필수기능/토큰 일치/링크/UTF-8/비밀값/신규 폴더 범위 검사. 앱 검증과 구분해요.
- DEMO Gate: 해당 단계의 P0가 모두 PASS여야 해요. 실제 재고·tenant·키오스크 항목은 Not Checked로 표시하고 운영 사용을 차단해요.
- 파일럿 Gate: 실제 SKU·매장·재고 adapter·권한 분리·기기·세션·실데이터 재검증이 필수예요.
- 상품화 Gate: 권리·개인정보·접근성·배포/rollback·운영 지원을 추가 검증해요.

## 실기기 기록 양식

기기 / OS / 앱 또는 브라우저 / build commit / camera / viewport / 조명 / 사용 거리 / 테스트 ID / 실제 결과 / evidence / 작성자 / 독립 검수 결과를 남겨요. Galaxy Z Flip5와 Galaxy Tab S10 FE+를 각각 실행해요. 키오스크 테스트를 두 기기의 결과로 대체하지 않아요.

## 성능 제안과 판정

30fps 목표, sustained 24fps 이상 후보, 상품 적용 p95 300ms 이하 후보, 인지 가능한 UI 피드백 100ms 이하 후보를 시작점으로 측정해요. 목표 수치는 보장값이 아니며 기기/추적 정확도/장시간 발열과 함께 초기 spike에서 확정해요. 단순 FPS 상승을 위해 오합성/개인정보 보호를 희생하지 않아요. 상반신 framing에서 눈 품질을 유지하는지 수치와 영상 관찰을 함께 검증해요.

실고객 얼굴을 QA 증거에 저장하지 않아요. 합성 fixture·비식별 계측·승인받은 제한 테스트 자료를 사용하고 원본 영상 저장이 필요하면 별도 승인을 받아요.
