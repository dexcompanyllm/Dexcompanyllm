## 확인한 사실

1. Pro $200(Pro 20X)의 신규 가입과 Free·Go·Plus·Pro $100에서의 업그레이드는 일시 중단됐어요.
2. 기존 Pro $200 구독은 계속 갱신되고 Pro $100은 영향을 받지 않아요.
3. 취소·다운그레이드는 현 결제 주기 종료에 발효되며, 종료 전에는 예약 변경을 되돌릴 수 있어요.
4. 공식 Pro 등급 FAQ는 조건을 충족한 계정에 접근 종료 뒤 최대 30일의 1회 복귀 경로를 설명해요. 실제 자격과 UI 제공 여부는 계정별 확인이 필요해요.
5. 에던 계정의 실제 등급·결제 종료일·예약 변경·복귀 자격은 확인하지 않았어요.
