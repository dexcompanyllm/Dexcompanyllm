# GitHub issue templates as structured feedback pattern

## Source Snapshot

- URL: https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/configuring-issue-templates-for-your-repository
- Publisher: GitHub Docs

## Key Notes

GitHub Docs는 issue template을 통해 contributors가 유용한 정보를 빠짐없이 제공하게 할 수 있음을 설명한다. 이 패턴은 growth scan report에도 적용할 수 있다.

## Why It Matters

매번 report 형식이 흔들리면 반복 학습이 어렵다. template은 무엇이 성공/실패/보류/개선인지 일정하게 남기는 데 유용하다.

## Dex Company Use Example

- growth scan report를 `Findings`, `Evidence`, `Failure Pattern`, `Action Items`, `Adoption Check`, `QA` 섹션으로 고정한다.
- 다음 실행에서 이전 action item을 자동으로 확인한다.
