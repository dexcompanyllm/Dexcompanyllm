# ChatGPT Images 2.5

## Confirmed

OpenAI 공식 발표에 따르면 ChatGPT Images 2.5는 ChatGPT, ChatGPT Work, Codex 사용자를 대상으로 desktop·mobile·web 전반에 rollout된다. 주요 변경은 다음과 같다.

- reference photo subject 보존과 자연스러운 조명·질감 개선
- 단일 요소 중심의 정밀 편집과 다중 턴 편집 일관성 향상
- generation latency 최대 50% 단축(Images 2.0 대비, OpenAI 발표 기준)
- ChatGPT 내 Sketch 입력, 이미지에 직접 comment를 남기는 편집 흐름, prompt 공유 기능
- transparent background를 포함한 복잡한 레이아웃 처리 개선

## Dex boundary

- CAPABILITY 지식으로만 기록하며, 특정 계정·기기·Workspace에 실제 노출됐다고 해석하지 않는다.
- 이미지 생성·편집 품질 향상은 Dex의 canonical state나 권한 모델을 자동 변경하지 않는다.
- 실제 산출물 생성 시에는 reference asset 출처, 사용 목적, 저작권·개인정보 검토를 별도 수행한다.
- 외부 게시·배포·광고 집행·유료 API 호출·자동 provider 전환은 이 note만으로 허용하지 않는다.
