# Skill — Agent Design

## Goal
Turn a business outcome into an executable agent definition without confusing generated text with completed work.

## Method
1. Define outcome and non-goals.
2. Define inputs and trusted sources.
3. Define delegation boundary.
4. Decompose work into nodes.
5. For each node define input, action, output, state, error, validation, and next connection.
6. Identify side effects and human-review points.
7. Define final acceptance criteria.
8. Execute a narrow pilot.
9. Validate actual output and record evidence.
10. Expand delegation only after repeated verified success.

## Agent definition
Use: Purpose / Input / Nodes / Tools or capabilities / Validation / Human Review / Output / Failure handling.

## Quality gate
A design is incomplete if it lacks an executable validation path, failure state, or ownership for consequential decisions.
