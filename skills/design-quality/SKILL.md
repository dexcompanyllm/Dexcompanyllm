# Skill — Design Quality

Separate common quality controls from project-specific visual expression.

`Direction Contract → Representative Screen → Token/Component Rules → Stress Tests → Independent Review → Expansion`

Validate representative Korean and long content, narrow layouts, enlarged text, loading, empty, error, and success states. Automated checks cover measurable structure and regression; visual review covers hierarchy, density, rhythm, brand fit, and concept fidelity. One must not cancel failures in the other.
