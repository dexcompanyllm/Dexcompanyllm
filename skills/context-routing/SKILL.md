# Skill — Context Routing

Use Dex Company with the least context needed for the current task.

1. Start from the Bootstrap core.
2. Identify the requested outcome and task class.
3. Identify capabilities required to complete and validate it.
4. Select only relevant Dex skills, playbooks, and templates.
5. Load additional context only when it can materially affect the work.
6. Keep company/client data in its authorized environment; Dex provides reusable methods, not a destination for that data.
7. Record missing capability or reference as a limitation rather than guessing.

Provider or model name is not a routing key.
