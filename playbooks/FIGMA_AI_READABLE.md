# Playbook — AI-Readable Figma Handoff

When representing agent/workflow designs in Figma, make operational meaning explicit.

Recommended fields:
- Node
- Input
- Output
- State
- Validation
- Error
- Connection
- Action

These fields are a Dex convention, not a universal Figma standard. Keep visual hierarchy readable for humans first, while naming layers/components consistently enough for connected AI tools to inspect.
