# Playbook — AI Agent PL

AI Agent planning structures work across Human + AI + System.

Ask: what outcome is required; what may be delegated; what is the execution order; where errors occur; how repeated errors are blocked; where human judgment is required; and whether execution was actually validated.

Flow: `As-Is → Delegation Scope → Work Order → Nodes → Error Points → Validation Gate → Human Review → Execution → Re-validation`.

For confidential work, migrate only generalized methods and synthetic examples into Dex Company.
