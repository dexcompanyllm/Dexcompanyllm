# Sanitization Guide

Before converting project work into Dex knowledge:

1. Remove organization, customer, employee, account, and environment identifiers unless public and necessary.
2. Remove internal URLs, APIs, repository paths, credentials, tokens, IDs, screenshots, and source code.
3. Replace real data with synthetic examples.
4. Keep the reusable decision rule, workflow, validation logic, and lesson.
5. Mark unsupported conclusions as inference or proposal.
6. Re-read the sanitized result as if the repository were public.

If the reusable lesson cannot be separated safely from confidential context, do not migrate it.
