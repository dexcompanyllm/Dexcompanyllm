# Security Boundary

Dex Company stores reusable operating knowledge, not private project source material.

Allowed: generalized methods, sanitized templates, synthetic examples, public evidence, reusable validation logic.

Excluded: confidential client/company material, private internal artifacts, authentication material, unnecessary personal information, and proprietary implementation details without authorization.

When uncertain, keep the source outside this repository and migrate only a generalized lesson that can stand on its own.
